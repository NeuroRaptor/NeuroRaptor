<h2>🔬 Research — Master's Thesis</h2>

<h3>Prompt Hallucination Detection &amp; Mitigation</h3>

<blockquote>
  Evidence-based verification framework for CLIP-based open-vocabulary object detection
</blockquote>

<p>
  <img src="https://img.shields.io/badge/Status-Completed-brightgreen"/>
  <img src="https://img.shields.io/badge/Model-OpenCLIP%20ViT--B%2F32-blue"/>
  <img src="https://img.shields.io/badge/Dataset-COCO-orange"/>
</p>

<p><strong>Key Results:</strong></p>

<ul>
  <li>🎯 <strong>71.2% false positive reduction</strong> (66 → 19 hallucinations)</li>
  <li>📉 <strong>25.8% hallucination rate reduction</strong> (40% → 29.69%)</li>
  <li>✅ <strong>Novel true-negative detection</strong>: 0% → 71.2% (47 correct rejections vs 0 baseline)</li>
  <li>📐 <strong>17.2% precision improvement</strong> (60% → 70.31%)</li>
  <li>🔁 Evaluated on <strong>165 COCO test cases</strong> across 4 hallucination types</li>
</ul>

<p>
  <strong>How it works:</strong><br/>
  Breaks down holistic CLIP similarity into patch-level attribute verification —
  checking whether specific visual properties of a queried object actually exist
  in the image, rather than relying on global semantic similarity.
</p>
